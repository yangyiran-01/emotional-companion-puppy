## 三个必测场景

1. **情绪倾诉**：新会话，发送“最近作业太多了，感觉每天都很累。”应显示 Concerned 和支持性回复，不应弹社交卡。再发“尤其是明天要交的作业。”检查能继续聊天且保留压力语境。
2. **开心分享**：点击 New conversation（移动端 +），确认 Start fresh，发送“今天终于完成了项目，好开心！”应变为 Happy，显示积极回应与摇尾/轻跳。
3. **孤独与建议**：新会话，发送“最近感觉很孤独，好久没有和朋友见面了。”应先获得支持，小狗 Concerned，出现 Accept 与 Not now。先点 Accept：应出现一个可自行执行的联系步骤，小狗 Encouraging，不能自动发送任何信息。再新建会话重复孤独消息，点 Not now：应出现尊重决定的反馈；再发“今晚还是有点孤独。”不应重复弹卡，仍可继续聊天。

可额外发送“我没有信心，不敢在课堂上发言。”查看 Encouraging；新会话默认 Calm。检查四种状态是否保持同一只小狗，表情和动作是否清楚。

## 可选补充检查

- 空白输入不能发送；Enter 发送，Shift+Enter 换行；中文输入法选词时不应误发送。
- 发出消息时有等待状态，重复发送被禁用。
- 可暂时断开本地 API 后发送，检查错误消息、原消息保留、Retry 和 Edit。恢复服务后重试。此操作仅用于测试进程，不修改真实聊天数据。
- 接受/拒绝后可以继续聊天。只有主动再次要求“给我一些社交建议”才应重新开放卡片。
- 调整为手机宽度，检查文字、按钮、输入区和聊天滚动；实际手机键盘仍待验证。
- 打开 About & privacy，检查 AI 身份、数据流和非专业咨询说明是否清楚。刷新后历史应消失。
- 如测试安全路由，请只用虚构测试句，不将它当作实际危机服务；应显示 Safety guidance 且无普通社交卡。
